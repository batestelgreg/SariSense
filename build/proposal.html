B. Project Proposal

1. Project Title

SariSense: An AI-Powered Demand Forecasting and Smart Restocking Web Platform for Sari-Sari Stores

SariSense is a responsive web application that helps sari-sari store owners decide exactly what to restock by recording their daily sales and using machine learning to forecast the next 7 to 30 days of demand for each product. It detects unusual sales patterns through anomaly detection and generates a prioritized restock list with suggested quantities and the capital needed. It also includes a Gemini-powered AI assistant that answers plain-language questions in Tagalog, Cebuano, or English — such as “Unsa akong paliton para sa sunod semana?” — based on the store's own sales data.

3. Outline of Main Features and Functionalities

ModuleKey Functionality
1. Store Setup & Onboarding Owner registers, creates a store profile, and selects a preferred language (Tagalog, Cebuano, or English). Products are added with cost price, selling price, and stock.
2. Sales Recording (POS-Lite) Mobile-friendly sales entry through a tap-to-sell product grid. Stock is deducted automatically and each transaction is logged with a timestamp for later analysis.
3. AI Forecasting Dashboard Per-product demand forecast for 7, 14, or 30 days as an interactive Chart.js line graph with confidence bounds. A Restock Priority table shows predicted demand, days until stockout, suggested order quantity, and the capital required.
4. Anomaly & Loss Detection Flags products or days with statistically abnormal sales — possible theft, spoilage, or encoding error — shown as plain-language alert cards with a one-tap verify action.
5. Conversational AI Assistant Chat grounded in the store's own forecast and stock data. Answers restocking and trend questions in the owner's chosen language and can generate a printable shopping list.
6. Reports & Export Weekly and monthly sales and profit summaries exportable to CSV for record-keeping and micro-financing.
Primary user workflow: Owner logs in → records the day's sales → the dashboard updates the forecast and alerts → owner reviews the prioritized restock list → asks the AI assistant for clarification → exports or prints the shopping list.

4. AI Component Description

4.1 Machine Learning Model / AI Algorithm

  • Demand forecasting — Gradient Boosting Regressor (scikit-learn). Trained on engineered features: day of week, payday proximity, holiday flags, and rolling 7/14/28-day averages. Quality is measured with MAE and MAPE on a held-out period, targeting MAPE below 20%. The model is serialized with joblib and loaded by the Flask API at startup.
  • Anomaly detection — Isolation Forest (scikit-learn). An unsupervised model trained on daily sales volume, basket size, and product mix to surface statistically unusual behavior without labeled data.
  • Restock prioritization — rule-based scoring layer. Combines forecast output, current stock, and supplier lead time to rank restock urgency and compute suggested order quantities.

4.2 AI API / Service

  • Google Gemini API — gemini-4-hydrogen, accessed through the current google-genai Python SDK. Context is injected as structured store aggregates (forecast values, stock levels, top sellers); no raw customer data is sent. A system instruction constrains the assistant to answer only from the supplied data and in the owner's chosen language.

4.3 Purpose and Function of AI

  • Prediction — forecasts short-term per-product demand, replacing guesswork with a data-driven estimate.
  • Anomaly detection — identifies unusual sales patterns indicating inventory loss, spoilage, or recording errors.
  • Recommendation — generates a prioritized restock list with suggested quantities and required capital.
  • Analysis (NLP) — lets non-technical owners query their own data conversationally in Tagalog, Cebuano, or English.

Design note: the core intelligence is a trained and evaluated machine-learning model, not a generic chatbot wrapper — the language model only translates model output into plain human language.
